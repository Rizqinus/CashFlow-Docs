# CashFlow Documentation Portal

Official documentation web portal for **CashFlow Online**, replicated from Help Accurate Online architecture. Built using React, Vite, and TypeScript.

## 🚀 Tech Stack
- **Framework:** React 18
- **Language:** TypeScript (.tsx)
- **Bundler:** Vite
- **Icons:** Lucide React
- **Architecture:** Modular Components (`Navbar`, `Sidebar`, `Footer`, `ModuleIndex`, `ArticlePages`)

## 📂 Project Structure
- `web-docs/` - Source code for React + Vite application
- `assets/` - Clean cropped UI screenshot assets and illustrations
- `docs/` - Markdown documentation references
- `extracted_template/` - Reference template archives from Accurate Online guide

## 🛠️ How to Run Locally
1. Navigate to the web documentation folder:
   ```bash
   cd web-docs
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:5173](http://localhost:5173) in your browser.
